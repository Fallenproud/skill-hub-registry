# Visual Asset Kit

The repository stores web-optimized preview WebP copies of the approved Skill Hub Registry visual system so the README and GitHub Pages site stay fast while preserving the generated composition.

- `readme/skill-hub-registry-hero.webp` — selected README hero
- `onboarding/01-hero-lockup.webp` — title/cover module
- `onboarding/02-trust-badges.webp` — feature badge strip
- `onboarding/03-registry-core.webp` — registry-core module
- `onboarding/04-capability-cluster.webp` — metadata/capabilities/policies cluster
- `onboarding/05-execution-cluster.webp` — dependencies/implementation/tests cluster
- `onboarding/06-pipeline.webp` — end-to-end package/runtime pipeline

The original generation-quality PNG sources remain outside the runtime registry and are not required by the compiler.
