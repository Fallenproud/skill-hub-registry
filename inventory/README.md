# Skill Archaeology Inventory

The inventory separates discovery from promotion.

- `historical-candidates.json` preserves the 35-entry July 14 archaeology ledger.
- `post-july-delta.json` records reusable capabilities discovered after that ledger through August 13, 2026.
- `duplicate-decisions.json` prevents multiple names from silently becoming competing canonical skills.

Candidates can exist at L0/L1 without appearing in the compiled runtime registry. Promotion into `skills/` happens only after provenance, boundaries, contracts, and maturity are sufficient.
