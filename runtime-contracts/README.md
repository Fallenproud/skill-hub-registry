# Runtime Contracts

Runtime contracts define how skills are discovered, authorized, invoked, observed, retried, and versioned. They are not agent instructions and are kept separate from `SKILL.md` cognition.

Current contract workstreams:

- registry identity/version/provenance
- signed skill execution and capability authorization
- human approval and safe mode
- append-only audit events
- fallback/retry/idempotency
- agent authority and revocation
- deterministic replay/verification
- runtime adapter normalization
