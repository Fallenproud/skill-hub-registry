# Leave No Reusable Skill Behind — Archaeology Protocol

1. Search chats, files, repositories, archives, worklogs, scripts, diagrams, and deployed systems.
2. Record the original source before rewriting anything.
3. Extract the transformation, not the project identity.
4. Classify evidence: implemented, documented, conceptual, simulated, deprecated, or unsafe.
5. Cluster duplicates by transformation and contract—not by name similarity alone.
6. Preserve project/domain profiles separately.
7. Promote only when invocation boundary, inputs, process, outputs, constraints, metrics, failure behavior, dependencies, and execution context are explicit.
8. Add tests/evidence before raising maturity.
9. Never discard useful source material merely because it is not yet canonical.
10. Never claim a source-derived capability executes until a verified runtime binding exists.
